# 🎬 Projeto Interdisciplinar — Clube da Luta

## 📚 Sobre o Projeto

Este é um projeto interdisciplinar desenvolvido pelos alunos:

- **Eduardo Luis Pinho S. S.**
- **Felipe Montez Pedro Filhos**

O projeto foi desenvolvido como parte das disciplinas de:

- Interfaces Web
- Arte Digital

## 💻 Desenvolvimento

Neste projeto, desenvolvemos uma página web inspirada no filme **Clube da Luta**, com versões adaptadas para computadores (desktop) e dispositivos móveis (mobile).

Durante o desenvolvimento, utilizamos diferentes tecnologias e ferramentas para a construção da interface, implementação das funcionalidades e criação dos elementos visuais:

- HTML5
- CSS3
- JavaScript
- JSX
- Adobe Illustrator
- Adobe Photoshop

O objetivo foi colocar em prática os conhecimentos adquiridos nas disciplinas, explorando conceitos de desenvolvimento web, design digital, criatividade e responsividade.

## 🎯 Objetivo

O projeto tem como finalidade integrar os conhecimentos de Interfaces Web e Arte Digital, proporcionando uma experiência prática de desenvolvimento de páginas web e criação de elementos gráficos.

## 🤝 Considerações Finais

Este é um projeto acadêmico, sem fins lucrativos, desenvolvido exclusivamente para fins educacionais.

Estamos abertos a críticas construtivas, sugestões e feedbacks que possam contribuir para o nosso aprendizado e para o aprimoramento de projetos futuros.
